# VRCLT 1.0.1

A small update to VRCLT 1.0. The Simple view gets VRChat's **Text only** switch
back, and the subtitle and language options stay in sight in both views.

## Changes

- **Text only in the Simple view:** VRChat's **Text only** switch is back next
  to the app choice. It passes your own voice straight through and adds the
  translation to the chatbox, without waiting for a translated voice. VRCLT 1.0
  had moved it to the Full view.
- **Subtitle and language options in both views:** the PC subtitle size,
  **Move subtitles**, **Reset subtitle pos**, and the UI language now sit right
  below the language cards in the Simple and Full views. Before, they were
  folded away at the bottom of the Full view.
- **Narrow windows:** at 780 px wide, the Full view no longer scrolls sideways.
- **New home:** the project moved to
  [github.com/VRCLT/VRCLT](https://github.com/VRCLT/VRCLT). Old links
  redirect, and VRCLT 1.0 still finds this update.
- **Guides on the wiki:** installation, API keys, engines, VRChat and VR, and
  troubleshooting moved from the README to the
  [wiki](https://github.com/VRCLT/VRCLT/wiki), in English, Korean, Japanese,
  and Chinese. The API key guide shows each provider's key page step by step.
  The Qwen guide now uses the `ws-` workspace ID that the current Model Studio
  console shows.

## Installation

Download `vrclt-v1.0.1-windows-x64.exe` and its `.sha256` checksum. Close the
old app before launching the new executable. Settings carry over from 1.0 in
`%LOCALAPPDATA%\vrclt\config.yaml`. On first start VRCLT asks once whether to
reset its settings; choose **No** to keep yours. Run the new executable once to
refresh the path used by SteamVR auto-start.

## Validation limits

The changes are covered by the regression tests, which run on GitHub's Windows
runner for every change. That runner also builds this executable. It has not
been checked on a headset or with live translation engines.
