# VRCLT 2.0

## 한국어

Windows용 VRCLT를 Rust로 다시 만들었습니다. 내 마이크 번역과 상대방 자막을 통역 콘솔 한 화면에서 조작할 수 있습니다.

- **엔진** 메뉴에서 Soniox, Gemini 3.5 Live Translate, Qwen, GPT를 선택할 수 있습니다. 화자를 구분하려면 Soniox를, 무료로 시작하려면 Gemini를 권장합니다. 각 서비스의 요금과 한도가 적용됩니다.
- **음성 및 텍스트**에서 번역 음성을 내 헤드폰으로 모니터링하고 음량을 조절할 수 있습니다. 텍스트 모드와 상대방 자막은 VB-CABLE 없이 쓸 수 있습니다. 케이블이 연결돼 있으면 텍스트 모드와 내 말 번역을 끈 상태에서도 마이크 원음을 케이블로 보냅니다.
- **자막**은 원문 표시, 글자 크기, 화자 구분, 대화 지우기를 지원합니다. SteamVR에서는 손목을 보면 메뉴가 나타나며 자막판을 잡아 옮기거나 크기를 조절할 수 있습니다.
- **잡음 제거**는 입력별로 켤 수 있습니다. CPU 필터와 선택형 NVIDIA Nemotron RE-USE GPU 필터를 제공합니다.

기존 VRCLT를 종료하고 아래 Windows x64 실행 파일을 여세요. 기존 설정과 API 키는 같은 위치에서 읽습니다. ZIP에는 같은 실행 파일과 라이선스가 들어 있습니다.

## English

VRCLT 2.0 brings microphone translation, incoming captions and setup checks into one native Windows console. Choose a separate engine for incoming speech, monitor your translated voice, or send text to the VRChat chatbox. VB-CABLE is optional for text and captions. When connected, it carries your original microphone in text mode and when outgoing translation is off.

The desktop overlay supports click-through, original text and adjustable font size. In SteamVR, look at your wrist to open the controls, grab the caption panel to move it, or drag a lower corner to resize it. SteamVR can start VRCLT automatically. Opening it again reuses the running console.

Close the previous version and run the Windows x64 EXE, or extract the ZIP and run `vrclt/vrclt.exe`. Both contain the same Rust executable and read `%LOCALAPPDATA%\vrclt\config.yaml`. Each download has a matching SHA-256 file.

If Windows reports a missing VCRUNTIME or MSVCP DLL, install the [Microsoft Visual C++ x64 runtime](https://aka.ms/vs/17/release/vc_redist.x64.exe).
