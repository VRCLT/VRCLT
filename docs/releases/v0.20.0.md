# vrclt v0.20.0

Qwen3.8 LiveTranslate is now the default Qwen model. It detects the spoken
language automatically and labels subtitles by speaker. This update also moves
Soniox to the connection authentication that Soniox requires from
15 January 2027.

## Changes

- **Qwen3.8 LiveTranslate:** new configurations use
  `qwen3.8-livetranslate-flash-realtime`. The same DashScope API key, endpoint,
  and workspace ID work with it.
- **No spoken-language setup for Qwen 3.8:** the model detects the language
  itself. The My/Their spoken-language pickers are hidden on the PC Dashboard
  and disabled on the SteamVR Dashboard while Qwen 3.8 is selected.
- **Speaker labels for Qwen:** Qwen 3.8 separates speakers. Each utterance's
  original and translated text carries its speaker number, shown with the same
  labels as Soniox in the PC preview, desktop overlay, and VR overlay. Speaker
  numbers are local to each connection.
- **Qwen 3.5 still available:** `qwen3.5-livetranslate-flash-realtime` works as
  before and still requires the spoken-language settings.
- **Soniox authentication:** speech recognition and translated voice now send
  the API key when the connection opens, as Soniox requires. Your saved key and
  settings do not change.
- **Documentation:** English, Korean, Japanese, and Chinese READMEs, Settings
  tooltips, and `config.example.yaml` describe Qwen 3.8.

## Switching an existing Qwen setup to 3.8

Saved settings keep the model they already have, so an existing Qwen setup stays
on Qwen 3.5 after the update. To switch, open **Settings**, set **Qwen model**
to `qwen3.8-livetranslate-flash-realtime`, and save. Your spoken-language
settings stay saved and apply again if you switch back to Qwen 3.5.

With Qwen 3.8, a subtitle line is not closed while the next utterance is already
being transcribed, so that utterance's original text stays with its translation.
When one person speaks without pausing, lines can therefore be longer than with
Qwen 3.5.

## Soniox: update before 15 January 2027

From 15 January 2027, Soniox refuses connections that send the API key the way
vrclt v0.19.1 and earlier do. If you use Soniox, update to v0.20.0 or later
before that date. No settings change is needed. See the
[Soniox WebSocket authentication guide](https://soniox.com/docs/guides/websocket-authentication).

## Installation

Download `vrclt-v0.20.0-windows-x64.exe` and its `.sha256` checksum. Close the old
app before launching the new executable. This is a single Windows executable
with a native PySide6 window and tray menu. VB-Audio Virtual Cable is required
for virtual microphone routing; select `CABLE Output` as the target app's
microphone.

Settings remain in `%LOCALAPPDATA%\vrclt\config.yaml`; no configuration file is
bundled alongside the executable. Run the new executable once to refresh the
path used by SteamVR auto-start.

## Validation limits

Qwen 3.8 and the Soniox authentication change are covered by local mock-WebSocket
tests built from the providers' published protocol documentation. Qwen 3.5 and
the PC and VR spoken-language controls are covered by regression tests. Paid
live Qwen and Soniox calls, live speaker-separation accuracy, and physical
headset behavior have not been verified.
