# VRCLT 1.0

VRCLT 1.0 is the release anyone can set up. A **Setup check** panel shows what
is ready, **Auto setup** fixes the audio routing and VRChat's settings, and
VB-Cable can be installed from inside the app. New installs open in a
**Simple** view with only the essentials, and the window fits smaller and
scaled screens, so nothing hides under the taskbar anymore.

## Changes

- **Setup check:** the top of the Dashboard checks the API key, VB-Cable, the
  translated voice output, your microphone, the Windows default playback
  device, and VRChat's microphone and OSC. Each item says how to fix it, and
  the panel folds to one line once everything is ready.
- **Auto setup:** sends the translated voice to `CABLE Input`, replaces a
  missing or virtual microphone with your real one (the microphone VRChat used
  before, otherwise the system default), and, while VRChat is closed, sets
  VRChat's microphone to `CABLE Output` for VR and desktop and turns on OSC.
- **Install VB-Cable:** downloads the official VB-CABLE package from VB-Audio,
  checks VB-Audio's digital signature, and opens VB-Audio's own setup. After
  you click **Install Driver** and close the setup, vrclt rereads the devices
  and continues with Auto setup. VB-CABLE is a donationware by VB-Audio
  ([www.vb-cable.com](https://www.vb-cable.com)), all participations are welcome.
- **Find my mic:** speak for a few seconds and vrclt selects the microphone
  that reacts most, on the desktop and on the SteamVR Dashboard's Audio page.
- **Nothing changes by accident:** Auto setup lists its changes and asks
  first, and **Undo** puts the previous VRCLT and VRChat settings back.
- **Simple / Full view:** new installs start in the Simple view: the setup
  check (one line once everything is ready), the app choice
  (VRChat/Discord/custom), runtime restart, translation and subtitle on/off,
  their languages, your microphone with **Find my mic**, a mic level bar,
  and the live subtitles. Switch to Full at the top right for voice output,
  the engine, and every other control. Settings saved by earlier versions
  keep the full view.
- **No more `CABLE Output` in the mic list:** the microphone pickers hide the
  cable's recording side, which would only feed the translated voice back.
- **Clearer audio routing:** the audio section spells out the path (your mic →
  VRCLT → `CABLE Input` ⇒ `CABLE Output` → the game's mic), and an empty device
  field names the system default it follows.
- **New README:** an overview with screenshots and a four-step quick start, in
  English, Korean, Japanese, and Chinese.
- **Fits the screen:** the window opens no larger than your screen's work
  area. Before, the bottom of the Dashboard and the Settings save button could
  sit under the taskbar on laptops or at 125–150% scaling.

## Notes

- Installing VB-Cable can make Windows switch its default playback device to
  `CABLE Input`, which silences your PC. The Setup check warns about this;
  use **Open sound settings** to set your speakers or headphones back as the
  default. VB-Audio recommends restarting the PC after installing. If the
  CABLE devices only appear after a restart, the Setup check says so;
  restart and start vrclt again, and Auto setup finishes on its own.
- vrclt changes VRChat's settings only when you press Auto setup and VRChat is
  closed, because VRChat overwrites its settings when it exits. The previous
  values are written to the log.
- Qwen sessions now log translations the server ends early and overlapping
  translated audio, to help diagnose clipped sentences.

## Installation

Download `vrclt-v1.0.0-windows-x64.exe` and its `.sha256` checksum. Close the old
app before launching the new executable. This is a single Windows executable
with a native PySide6 window and tray menu. VB-Audio Virtual Cable is required
for virtual microphone routing; the Setup check can install it for you.

Settings remain in `%LOCALAPPDATA%\vrclt\config.yaml`; no configuration file is
bundled alongside the executable. Run the new executable once to refresh the
path used by SteamVR auto-start.

## Validation limits

The setup rules, auto setup, VRChat settings writer, installer steps, mic
finder, and both dashboard views are covered by local tests that use no
registry writes, network, or audio devices. The VB-CABLE download and signature
check were run against VB-Audio's server, and the mic finder was opened on real
devices without speech. A full VB-CABLE installation on a clean PC, Auto setup
against a real VRChat installation, and mic detection while speaking have not
been verified.
